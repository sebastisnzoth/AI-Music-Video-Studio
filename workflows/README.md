# ComfyUI workflows

AI Music Video Studio uses **API-format ComfyUI JSON workflows** from this folder.

The first workflow slot is:

- `scene.json` — generate a scene clip from the project reference image and scene prompt.

Export a working workflow from ComfyUI using **Save (API Format)** and store it as `workflows/scene.json`.
You can use these placeholders in any string field:

- `{{prompt}}` — scene prompt generated by the music-video storyboard
- `{{scene_id}}` — numeric scene id
- `{{duration}}` — requested scene duration in seconds
- `{{reference_path}}` — absolute path to the uploaded artist photo/video
- `{{output_prefix}}` — output prefix inside the current project

The app replaces the placeholders and submits the workflow to the local ComfyUI `/prompt` endpoint.

## Goal

The default production stack is intentionally provider-free:

1. local audio analysis (librosa)
2. local transcription (Whisper/faster-whisper, optional next layer)
3. ComfyUI image/reference workflow
4. local image-to-video / audio-to-video model
5. local lip-sync model when the shot shows singing
6. FFmpeg final assembly with the original song

No paid API is required by this integration.
